%%PNEUMA free start / %%PNEUMA free end — wrap rubato/cadenza sections in free time (±20% random scaling).

%%BREATH auto N — insert N-tick micro-rest at every bar line. 25-40 for natural phrasing.
%%BREATH bars N — insert breath only every N bars.
%%BREATH after N — also insert breath after notes exceeding N ticks duration.
%%BREATH off — disable for relentless passages.

%%GRAVITY phrase N — set phrase grouping to N bars.
%%GRAVITY weight W1 W2 W3 W4 — velocity multiplier per bar within phrase. 1.15 1.0 0.9 0.85 = natural.
%%GRAVITY agogic A1 A2 A3 A4 — duration multiplier per bar within phrase. 1.05 1.0 1.0 0.95 = rubato.
%%GRAVITY off — disable for mechanically flat passages.

%%ARTICULATE auto — enable all context-aware articulation rules with defaults.
%%ARTICULATE repeated F — scale duration of repeated pitches by F (0.85 = shorter repeated notes).

%%ARTICULATE phraseend F — scale duration of notes before rests/barlines by F (1.15 = sustained endings).
%%ARTICULATE staccato F — set staccato note duration ratio (0.5 = half length).
%%ARTICULATE off — disable.

%%ENSEMBLE offset N — global onset shift for all voices (signed ticks).
%%ENSEMBLE jitter N — random ±N tick variation per note per voice.
%%ENSEMBLE voice N — per-voice constant offset. Positive = late/expressive, negative = early/driving.

%%SPATIAL group X voices N,N,N — define spatial group X containing listed voice numbers.
%%SPATIAL delay X Y N — N milliseconds delay between groups X and Y (simulates physical distance).

%%TRANSFORM invert — mirror pitches around the inversion axis.
%%TRANSFORM invertaxis N — set inversion axis (MIDI pitch, default 60 = middle C).

%%TRANSFORM pitchshift N — transpose all pitches by N semitones.
%%TRANSFORM timescale F — scale all note/rest durations by factor F.
%%TRANSFORM delay N — prepend N bars of rests before transformed content.
%%TRANSFORM off — disable transform for this voice.
Operations apply in order: retrograde → invert → pitch shift → fragment → time scale.
